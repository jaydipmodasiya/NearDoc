PROJECT
=======
Project Name  : NearDoc — Campus Printing System
Project Type  : Static Web Application (Frontend-only)
Current Status: Completed (v1.0) — Fully functional with localStorage persistence
GitHub Ready  : YES

TECHNOLOGY
==========
Frontend  : HTML5, Vanilla CSS (custom design system), Vanilla JavaScript (ES6+)
Backend   : None — runs entirely in the browser
Database  : Browser localStorage (no external database required)
APIs      : PDF.js (via CDN, for client-side PDF parsing)
Fonts     : Google Fonts (Fraunces, DM Sans)
Tools     : No build tools required — open directly in a browser

PAGES
=====
NearDoc.html        : Main student-facing app (upload, order, track, profile)
NearDoc-auth.html   : Login & registration for students and shop owners
NearDoc-shop.html   : Shop owner dashboard (manage orders, settings, profile)
NearDoc-admin.html  : Admin panel (shop verification, user/order management)

GITHUB SAFETY
=============
This repository is intentionally prepared for public GitHub publication.

The following types of files are EXCLUDED from this repository:
  - Academic reports, presentations, and project submissions
  - PDF, PPTX, DOC, DOCX, and other office documents
  - Personal information of group members, faculty, or students
  - Student IDs, roll numbers, enrollment numbers
  - Contact information (phone numbers, private emails)
  - College/university internal information
  - Credential files or files containing private business data

FILES INTENTIONALLY EXCLUDED
=============================
presentation/                        : Contains a project presentation (PPTX)
  └── NearDoc - Campus Printing System.pptx   (~8.5 MB, academic presentation)

These files are listed in .gitignore and will NOT be tracked by Git.

SECRETS
=======
This project has NO external API keys, database credentials, or backend secrets.
All data is stored in the user's own browser (localStorage) and never transmitted
to any external server. The admin panel uses demo credentials (hardcoded for
demonstration purposes only — not real credentials):
  admin@neardoc.local / admin123

There are no .env files or secret configurations required.
